### 已验证组件 (3/5)

2. **PushDeer 推送通道** — 正常工作，API 响应正常，通知成功发送

### 未验证组件 (2/5)

5. **FCM 推送** — 需要 Firebase Admin 初始化，建议通过 GitHub Actions 验证

### 发现的问题

1. **AkShare 盘中高低值缺失** — 非交易时段 `最高`/`最低` 返回 0。这不影响核心功能（跌幅计算只依赖 `最新价` 和 `昨收`），但前端展示时需要处理零值情况。

2. **AkShare 调用耗时** — 约 33 秒完成全量 ETF 数据下载。在 GitHub Actions 环境中需确保不超时。每 10 分钟调度一次，33 秒的获取时间完全可接受。
